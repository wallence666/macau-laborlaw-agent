# 法源政策

## 法域

唯一法域是澳門特別行政區。其他法域的文本不得直接套用。

## 可進入檢索的來源

只有同時符合以下條件的來源才可被檢索：

1. 來源為澳門官方公布、官方機構發布或經法律審核者核准的資料。
2. `review_status` 為 `approved`。
3. `jurisdiction` 為 `MO`。
4. 事件日期落在 `effective_from` 與 `effective_to` 之間。
5. 條文具有可追溯的官方網址、版本標籤與校驗碼。

`review_scope=production` 代表已經真人法律覆核；`review_scope=test_only` 只代表專案擁有者授權本機測試。Agent 使用測試來源時必須在回答風險欄位顯示警告。

`approved_commentary` 不得單獨支持法律結論。

## 版本

- 日期一律使用 ISO 格式，例如 `2026-09-15`。
- 舊版本不得直接刪除。
- 同一條文在同一生效日期出現不同有效內容時，工作流會標示版本衝突並要求真人處理。
- 中文與葡萄牙文版本應各自保存並以相同 `provision_id` 主體關聯。

## 更新

來源更新後必須建立新快照、比對差異、由法律審核者確認、設定生效日期、重建索引並跑回歸測試。未完成這些步驟前，不得把新內容當作已核准來源。

## 私隱

案件資料與法源資料必須分開儲存。審計紀錄只保存完成追溯所需的最少欄位，預設不保存原始查詢、姓名、證件號、醫療資料或聯絡方式。
